# Marcelo Gás

Landing page de conversão para o Marcelo Gás, em Poções (BA), com pedido direto pelo WhatsApp, consulta do programa Gás do Povo, localização, FAQ e eventos de mensuração preparados.

## Desenvolvimento

```bash
npm install
npm run dev
```

Validações disponíveis:

```bash
npm run lint
npm run typecheck
npm run build
```

## Mensuração

Copie `.env.example` para `.env.local` e preencha apenas os serviços utilizados:

```env
NEXT_PUBLIC_GA_ID=
NEXT_PUBLIC_GTM_ID=
NEXT_PUBLIC_META_PIXEL_ID=
```

Os CTAs incluem contexto, UTM e `data-cta-location`. Nenhum identificador de Analytics, GTM ou Meta Pixel é publicado por padrão.
